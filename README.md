# Hostel Management System

## About the Project
This is a simple Python program for managing hostel student records.

It allows the user to:
- Add a student
- View all students
- Search for a student
- Update student details
- Delete a student
- Exit the program

## Student Details
The program stores:
- Roll Number
- Name
- Room Number
- Hostel Fees

## Requirements
- Python 3

No extra libraries are required.

## How to Run
1. Install Python 3.
2. Open the project file:
   `PROJECT [Hostel Mangment System].py`
3. Run the file.
4. Choose an option from the menu by entering a number from 1 to 6.

## Menu

| Choice | Function |
|---|---|
| 1 | Add Student |
| 2 | View Students |
| 3 | Search Student |
| 4 | Update Student |
| 5 | Delete Student |
| 6 | Exit |

## Example
When adding a student, enter:
- Roll Number: 101
- Name: Rahul
- Room Number: A-12
- Hostel Fees: 5000

The student record will then be stored and can be viewed, searched, updated, or deleted.

## Note
The records are stored only while the program is running. They are not saved permanently in a file or database.
